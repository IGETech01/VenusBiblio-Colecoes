# VenusBiblio | Coleções públicas IGETech

Repositório oficial de **coleções públicas** do Workshop VenusBiblio.

O catálogo poderá ser acessado de qualquer lugar com internet. Após o download,
cada livro permanece na biblioteca local para leitura offline.

## Estado do catálogo

**Aguardando a primeira coleção autorizada.** O índice público está disponível em
[`workshop/colecoes.json`](workshop/colecoes.json), inicialmente sem livros.

O aplicativo VenusBiblio consulta este arquivo para descobrir as coleções.
Os catálogos e capas ficam neste repositório; os arquivos PDF, EPUB e CBZ
são distribuídos como anexos de **GitHub Releases** específicos de cada coleção.

## Disponibilizar uma coleção

Consulte [Como publicar uma coleção](docs/COMO_PUBLICAR.md). O aplicativo possui
uma ferramenta administrativa para preparar os arquivos de publicação.

**Não publique livros sem direito de redistribuição.** Inclua apenas obras em domínio
público ou cuja licença/autorização permita a distribuição. Os arquivos publicados
aqui ficam acessíveis a qualquer pessoa.

## Downloads do aplicativo

Para instalar o VenusBiblio, use o repositório separado:
[VenusBiblio-Updates](https://github.com/IGETech01/VenusBiblio-Updates/releases/latest).

Este repositório não distribui executáveis, credenciais, ferramentas administrativas,
código-fonte privado, contas ou bancos de dados de usuários.
